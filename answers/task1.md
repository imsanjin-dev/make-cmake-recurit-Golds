# Task 1：从 C 源码到可执行文件

一个 C 程序从源文件到最终可执行文件，大致会经历预处理、编译、汇编和链接四个阶段。
1. 预处理：主要处理 `#include`、宏定义和条件编译等内容，也会去掉注释。
2. 编译：把预处理后的 C 代码转换成汇编代码，并在这个过程中进行语法、类型等检查，也可能对程序做一些优化，最终得到仍然可以直接阅读的 `.s` 汇编文件。
3. 汇编：把汇编代码转换成机器能够识别的目标文件 `.o`。这时文件已经不是普通文本，而是二进制的机器码和一些符号、重定位信息，但它还只是一个半成品，不能直接运行。
4. 链接：把一个或多个 `.o` 目标文件以及程序需要使用的库组合起来，解决外部函数和变量的引用，最终生成可以直接执行的程序。
